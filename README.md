## Estoque Celma - Admin & Catálogo

Projeto Next.js com MongoDB Atlas para gerenciamento de produtos (materiais de construção) e catálogo público, pronto para deploy na Vercel.

### Scripts

- `npm run dev` - Ambiente de desenvolvimento
- `npm run build` - Build de produção
- `npm start` - Servir build de produção

### Variáveis de ambiente

- `MONGODB_URI` - String de conexão do MongoDB Atlas
- `ADMIN_PASSWORD` - Senha simples para acessar o painel `/admin`
- `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_UPLOAD_PRESET` (opcional, se usar Cloudinary)
